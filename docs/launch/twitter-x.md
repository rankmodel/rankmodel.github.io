# X / Twitter launch thread

🧵 We shipped ModelRank — the independent leaderboard for AI models. No lab owns it, no paywall, no pay-to-play. Here's why it exists and what it does. 🧵

1/ HuggingFace tells you what models exist. It does not tell you which are actually good. ModelRank does, with a transparent weighted score and head-to-head win probabilities instead of a black box.

2/ Five dimensions: benchmarks, efficiency, community, recency, reproducibility. Every score is reproducible from public signals. We don't train models, so we have zero reason to rank our own higher.

3/ Head-to-head ELO. Compare any two models, vote on the winner (human or LLM judge), and watch live standings form. Link: https://rankmodel.github.io/head-to-head.html

4/ Free embeddable badges. Drop one in your README and you're on the board. Every badge links back. https://rankmodel.github.io

5/ Built for builders: a zero-dependency Python SDK, LangChain and LlamaIndex tools, and a VS Code extension that shows a model's score on hover.

6/ A weekly newsletter, published automatically, with the efficiency king, the freshest model, and trending picks. https://rankmodel.github.io/weekly.html

7/ Open source (MIT). Run it locally, score your own fine-tunes, embed the badges. https://github.com/rankmodel/rankmodel.github.io

If you think AI evaluation should be transparent and community-owned, star it and reply with the model you want us to score next. 🏆
