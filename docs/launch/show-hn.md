# Show HN

**Title:** Show HN: ModelRank – an independent, open leaderboard for AI models

Most leaderboards are run by a lab, hidden behind a paywall, or tuned to make one
model look good. ModelRank is the opposite. It is a conflict-of-interest-free
leaderboard that scores open-weight models with transparent, reproducible signals
instead of hype.

- 5-dimension scoring: benchmarks, efficiency, community, recency, reproducibility
- Head-to-head ELO with community and LLM-judge verdicts
- Free embeddable badges you can drop into your README
- A Python SDK, LangChain and LlamaIndex tools, and a VS Code extension
- A weekly newsletter, published automatically

No vendor spin, no pay-to-play. The score is the same for everyone.

Try it: https://rankmodel.github.io
Code: https://github.com/rankmodel/rankmodel.github.io

If you think AI evaluation should be transparent and community-owned, star it and
tell me which model we should score next.
