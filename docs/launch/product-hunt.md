# Product Hunt

**Tagline:** The independent, open leaderboard for AI models
**URL:** https://rankmodel.github.io
**Category:** Developer Tools / Artificial Intelligence

**First comment:**
ModelRank is a conflict-of-interest-free leaderboard for open-weight AI models.
We do not train or host models, so we have no reason to rank our own higher.

What you get:
- Transparent 5-dimension scoring (benchmarks, efficiency, community, recency, reproducibility)
- Head-to-head ELO with community and LLM-judge verdicts
- Free embeddable badges for your README
- A Python SDK, LangChain/LlamaIndex tools, and a VS Code extension
- A weekly newsletter

It is open source (MIT) and free to use. Star it on GitHub if independent
evaluation matters to you: https://github.com/rankmodel/rankmodel.github.io
