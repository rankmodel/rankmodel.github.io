# Claude Desktop Agent Guidelines for ModelRank

## MCP Tools Available
- `search_codebase`: Query symbols, classes, functions, and file summaries.
- `get_file_context`: Detailed AST breakdown and imports/dependents graph.
- `send_agent_message`: Publish updates to `ongoing-edits` or `architecture`.
- `read_agent_messages`: Check live communication feed from Cursor, Windsurf, Antigravity.
- `record_codebase_memory`: Persist decisions and lessons learned.
