# GitHub Trending Insights (AI/LLM domain)

## Patterns & Tech Stack Analysis
- **Languages:** Python is dominant for orchestration, TS/React for UI.
- **Dependency Management:** Heavy shift toward `uv` and `poetry`. Requirements.txt still common for legacy.
- **Testing:** `pytest` is universal. Coverage thresholds typically 80%+ in top tier.
- **CI/CD:** GitHub Actions (ruff/black/isort linting + pytest + pyright/mypy type checking).
- **Security:** Dependabot, CodeQL, pre-commit hooks for secret scanning.
