API Reference

Integrate objective AI scoring and rankings into your applications.

Overview

Base URL

All API requests should be prefixed with this base URL.

https://your-deployment.com

Authentication

Free tier doesn't require auth. Pro tier requires an API key passed in the headers.

X-API-Key: mr_xxxxxxxx

Rate Limits & Info

Plan Rate Limit Auth Required
Free 100 req/hr No
Pro 5,000 req/hr Yes
Enterprise Unlimited Yes

SDKs

Coming soon: Python SDK, JavaScript SDK

Versioning

Current API version is v2.0.0

GET

/health

System health and leaderboard stats.

Parameters

No parameters required.

Example Request

$ curl https://your-deployment.com/health

Example Response

{
  "status": "ok",
  "uptime_seconds": 86400
}

GET

/score/{model_id}

Get the full composite score and basic tier details for a specific model.

Parameters

NameTypeDescription
model_id path HuggingFace model ID (e.g. Qwen/Qwen3.5-9B)

Example Request

$ curl https://your-deployment.com/score/Qwen/Qwen3.5-9B

Example Response

{
  "model_id": "Qwen/Qwen3.5-9B",
  "composite": 81.52,
  "tier": "A",
  "breakdown": {
    "benchmarks": 82.0,
    "efficiency": 46.3,
    "community": 67.7,
    "recency": 74.2,
    "reproducibility": 55.0
  },
  "computed_at": "2026-08-13T15:25:01Z",
  "confidence": "high",
  "coverage": {
    "found_benchmarks": 8,
    "total_benchmarks": 13,
    "coverage_percent": 61.5
  }
}
GET

/score/{model_id}/extended

Score + 10 extended metadata signals (context window, vram tier, license score, etc).

Parameters

NameTypeDescription
model_id path HuggingFace model ID

Example Request

$ curl https://your-deployment.com/score/Qwen/Qwen3.5-9B/extended
POST

/score/batch

Score multiple models at once (up to 20).

Parameters

Accepts a JSON body with an array of model IDs.

{ "models": ["Qwen/Qwen3.5-9B", "google/gemma-4-31B-it"] }

Example Request

$ curl -X POST https://your-deployment.com/score/batch   -H "Content-Type: application/json"   -d '{"models": ["Qwen/Qwen3.5-9B"]}'

POST

/judge/human

Record a human head-to-head verdict. Updates both models' ELO ratings. No LLM call.

Request Body

FieldTypeDescription
model_astringFirst HuggingFace model ID
model_bstringSecond HuggingFace model ID
verdictstringOne of: A, B, tie

Example Request

$ curl -X POST "https://your-deployment.com/judge/human" \
  -H "Content-Type: application/json" \
  -d '{"model_a":"Qwen/Qwen3.5-9B","model_b":"deepseek-ai/DeepSeek-R1","verdict":"A"}'

Example Response

{
  "review_id": "human-a1b2c3d4e5f6",
  "verdict": "A",
  "model_a": "Qwen/Qwen3.5-9B",
  "model_b": "deepseek-ai/DeepSeek-R1",
  "elo": { "a": 1512, "b": 1488 }
}
GET

/judge/{model_a}/{model_b}

Run the LLM-judge vibe-check on two cached models and persist the verdict (updates ELO). Configure the judge via JUDGE_API_BASE / JUDGE_API_KEY / JUDGE_MODEL.

Parameters

NameTypeDescription
model_apathFirst HuggingFace model ID
model_bpathSecond HuggingFace model ID

Example Request

$ curl "https://your-deployment.com/judge/Qwen/Qwen3.5-9B/deepseek-ai/DeepSeek-R1"

Example Response

{
  "review_id": "llm-9f8e7d6c5b4a",
  "verdict": "B",
  "rationale": "DeepSeek-R1 reasons more reliably on hard prompts.",
  "model_a": "Qwen/Qwen3.5-9B",
  "model_b": "deepseek-ai/DeepSeek-R1",
  "elo": { "a": 1490, "b": 1510 }
}

GET

/reviews

Community + LLM-judge head-to-head verdict feed, most-recent first.

Query Parameters

NameTypeDescription
limitintMax rows (default 50, max 200)
model_idstringFilter to reviews involving this model
judge_typestringhuman or llm

Example Request

$ curl "https://your-deployment.com/reviews?judge_type=llm"

Example Response

{
  "total": 1,
  "reviews": [
    { "review_id": "llm-9f8e7d6c5b4a", "model_a": "Qwen/Qwen3.5-9B", "model_b": "deepseek-ai/DeepSeek-R1", "verdict": "B", "judge_type": "llm" }
  ]
}
